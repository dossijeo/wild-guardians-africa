Cómo se coloca el poblado

Primero se generan los obstáculos. Después se comprueba la huella de cada conjunto, manteniendo la disposición original del poblado. Una colisión con un árbol o una roca omite el conjunto entero: no se recorta ni se reubica. La hierba es decorativa y no bloquea la construcción.

Activa las huellas para ver el diagnóstico, o pon ambos contadores de obstáculos a cero para observar el poblado completo. La orientación cambia el poblado, no el terreno.
