Loaded the real candidate GLB via actor-expression.html?actor=rhino, using ActorExpression and the original clips. Ten facial bindings, five draw calls, no reported errors. Neutral, half blink, combined pain and Running at 0.4 seconds were inspected. Screenshots and runtime state attached.
