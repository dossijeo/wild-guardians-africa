# Facial UV seam edge diagnosis

Run `node tools/guardian/audit_worker_seam_edges.mjs ORIGINAL.glb REPAIRED.glb` with the original olderFemale hash and the output of experiment_worker_normal_seams.mjs. The first input defines the shared edge set, excluding source geometric normal discontinuities over 0.5 radians; subsequent inputs use exactly that set. Compare identical geometry/UV topology, not the incised expressive mesh.

The recorded edge-continuity.json compares 203 shared facial seam edges, sampling both sides at endpoints and at 25%, 50%, 75% along each edge. For interior samples, the original normal-map angular mismatch has median 16.36 degrees and p95 32.85 degrees; repaired median is 3.76 and p95 27.36. Endpoint frame correction helps substantially but leaves a long tail of interior discontinuities. This supports investigating edge-interior continuity instead of increasing vertex correction indiscriminately.

The calculation interpolates UVs and tangent frames and bilinearly samples the embedded normal map at its base level. It is a diagnostic approximation: it excludes mipmapping, derivatives, lighting and animation. It writes no model or image data. The remaining raking-light artifacts are still not accepted, and the surface candidate remains uninstalled. Preserving image bytes alone does not prove wrinkle appearance; eventual correction must also be inspected under studio and both raking lights.

## Bounded edge-fit experiment

`node tools/guardian/experiment_worker_normal_seams.mjs test-results/olderFemale-edge-fit.glb --edge-fit` adds 16 offline relaxation iterations using five samples per seam. Additional normal rotation is limited to 0.15 radians from the endpoint-corrected frame; large mismatches over 60 degrees are skipped. The byte whitelist still enforces unchanged topology, images, skin and animations. Default behavior without the flag remains unchanged.

edge-fit-comparison.json uses the same 203 edges: interior median 2.46 degrees, p95 21.37 degrees, versus endpoint-only 3.76/27.36. This is an improvement, not elimination of seams. Transfer with transfer_normal_frame_corrections.mjs into test-results/olderFemale-edge-fit-expressive.glb matched 20,750 vertices, interpolated 83 incision vertices, corrected 531, and left zero unmatched; other binary data remained unchanged. The existing transfer regression test passed.

The fixture exposes `actor=olderFemale&edgeFrameTrial` for the original and `actor=olderFemale&edgeExpressiveTrial` for the transferred expressions. Viewed both profiles with opposing raking lights and pain (full blink, mouth 0.85). Cheeks retain wrinkles and look smoother, but the opposite profile reveals white eye exposure at full blink: edge-fit-opposite-profile.png. This blocks installation independently of the material experiment. Inspect and repair that lid contour/rim next; prior one-sided v4 evidence did not cover this defect. Neck facets also remain visible outside the facial correction region. No catalog or committed candidate GLB was replaced.
