# Confirmed motion in a WebGPU presentation Worker

`createConfirmedGpuMotion` converts an already observed, continuous, timed authority `motionTrace` into a fixed-size floating-point GPU texture. A TSL position node reads it and clamps movement at its final confirmed time; `hold(time)` can further restrict that horizon. Material bindings use the inverse world matrix for translation after skinning; they never change the object's root transform or simulation state. Materials currently need to be private to an actor, since the uniforms and trajectory texture are per actor. `dispose` removes the bindings and releases the texture.

The caller owns one shared simulation-time uniform, actor root placement, confirmed state ordering and error handling. Install a trace only after validating it against the same accepted authoritative publication, and anchor the actor root at the trace's starting world position. `hold` cannot retract pixels already displayed; an invalidation affecting already-presented time requires hiding/reconciliation by the caller. Without a validated trace or while physical poses take authority, use the existing presentation path. The component does not anticipate movement or certify collisions between concurrent trajectories. `trackPathMotion` is currently diagnostic and only tracks a selected actor: this is not an integrated feed for gameplay or a safe predictive horizon.

`tests/confirmed-gpu-motion.test.js` checks ordered installation, bounded size, transactional validation and hold behavior. `tools/experiments/audit_confirmed_gpu_motion_webgpu.mjs` runs in an OffscreenCanvas Worker with a strict WebGPU backend. Its primitive moved from pixel center 127.5 to 191.5 and stopped at its confirmed end; shortening the horizon held at 159.5. The original warthog GLB (four skinned meshes) moved from 127.32 to 191.32 and held at 191.32. Both traces in this audit are synthetic; no live game state, skeleton animation, shadows, physics, invalidation race or actor-to-actor safety is validated. No performance improvement is asserted. Before gameplay use, provide a live authoritative trace feed, ordered invalidation with reconciliation, paused/speed-adjusted simulation time, correct actor root and terrain placement, multi-actor coordination, shadows/animation, and integrated visual and gameplay tests.
