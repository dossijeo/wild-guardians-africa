# Wrist candidate review

Rendered the editable original and isolated candidate in Blender Cycles, Attack + Float + Mantle_Spell at frame 13, identical close camera and lighting aimed at the diagnosed right-wrist edge. Generator: tools/guardian/render_guardian_wrist_trial.py; candidate generator: study_guardian_hand_weights.py.

Inspected original.png and candidate.png. The pose, wood hand silhouette and adjacent ornament remain similar; the visual difference is too small to establish a meaningful quality improvement. Numeric edge-ratio reduction alone is insufficient reason to replace production weights. This trial is therefore not adopted. Original source and runtime assets remain untouched. This does not certify every hand pose or claim all deformation is ideal; the intended next visual focus is the larger mantle transition region.
