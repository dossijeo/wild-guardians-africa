# Fondo de lápiz en cinemáticas WebGPU

En el perfil de juego con Worker gráfico, la cinemática usa un segundo Worker con OffscreenCanvas y WebGPU para el efecto de lápiz. El Worker compila el pipeline de forma asíncrona, descarga y decodifica el fondo y la guía, y es dueño de las texturas; el hilo de interfaz solo envía escena, tamaño y progreso. La ilustración original permanece visible hasta el primer dibujo enviado. Los cambios de escena cancelan las descargas anteriores, y las peticiones de dibujo pendientes se consolidan. Un fallo del Worker conserva el fondo original. La ruta legada conserva WebGL y la preferencia de movimiento reducido sigue desactivando el efecto.

`tools/guardian/check_cinematic_pencil_webgpu.mjs` compara el primer fondo real con la ruta WebGL de referencia. Con Vite en `127.0.0.1:5399`, Edge headless y el adaptador WebGPU identificado como NVIDIA/Turing, los errores absolutos medios en la última ejecución fueron 0,000051 / 0,000252 / 0,000049 sobre 255 a progreso 0,2 / 0,4 / 0,8; los máximos fueron 1 / 1 / 1. Las capturas y JSON quedan en `.cache/cinematic-pencil-webgpu`. Es una comparación de tres cuadros de una escena, no demuestra paridad de todas las cinemáticas ni mejora de rendimiento. No se ha medido el coste de segundo contexto/dispositivo, carga duplicada de imágenes o fluidez en la transición integrada.
