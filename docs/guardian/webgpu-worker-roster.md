# Confirmed workers in the WebGPU presentation Worker

`createWebGpuWorkerRoster` reconciles active worker IDs and profiles from the confirmed presentation state. Home workers are removed, late loads cannot resurrect removed workers, and each actor owns its skeleton and mixer. `createWebGpuWorkerBank` loads the existing original GLB, action definitions and precooked recovery bank in the render Worker; models of the same profile share geometry, materials, textures and animation clips. The existing worker pose, tools and facial expression logic runs on confirmed state updates. Terrain height is sampled from the resident native terrain mesh with a center ray and the existing worker offset.

`tests/webgpu-worker-roster.test.js` verifies sharing, reconciliation and cleanup. `tools/experiments/audit_webgpu_worker_roster.mjs` renders two fleeing olderFemale workers from the mangrove raid fixture in a strict WebGPU Worker; the run reported 2 ready and 7 draw calls. This test exercises original rigs and clips, not an integrated full raid, appearance parity, GPU animation, detailed terrain contact, or frame-time performance. One pending profile load can continue after its last requesting actor disappears, but the late actor and source are released; closing the bank aborts loading. Shadows, lighting and other world content depend on the parent surface and remain incomplete.
