# Confirmed biome vegetation in WebGPU Worker

The existing terrain publication carries copied Wild Engine instance metadata for each confirmed chunk, ordered with that chunk's revision and terrain. The Worker loads the existing biome pack and texture assets, and creates instanced tree, shrub, plant and solid-prop meshes (slots 0–18). The authority's suppression IDs determine which instances remain visible. Chunk revisions prevent stale replacements. Geometries and materials are shared between chunks; the Worker releases chunk instances, image bitmaps, textures and geometry on disposal. This is a visual consumer, not another world generator or navigation authority.

The existing near-tree UV geometry, reviewed triangle cleanup and near atlases are reused. The current integration uses the highest-detail geometry and near maps for every distance: LOD/impostors, wind, AfricanToon, precise lighting, shadows, wet and lava variants of slot 19 and other world objects are not yet migrated. `MeshStandardMaterial` and the lights are provisional, so this is not visual parity or a performance optimization. Chunk removal/eviction still requires an authoritative removal publication.

`tests/webgpu-biome-props.test.js` checks replacement, stable revisions, suppression and resource disposal; `tests/terrain-publication.test.js` checks that instance data is copied and published only on commit. `tools/experiments/audit_webgpu_confirmed_terrain.mjs` runs the real mangrove-island authority and checks native terrain, water and vegetation in WebGPU. One smoke run observed 8 confirmed chunks and 71 vegetation batches; this is neither a gameplay-completion test nor a performance measurement. The game entry point remains behind its development gate, with the old scene running underneath.

Solid props in slots 10–18 use the same confirmed transforms and shared native pack geometry. Slot 19 is also rendered in the desert, whose authored asset is dry and needs no chunk clipping; in other biomes it remains omitted pending native clipping and water or lava presentation. In a mangrove smoke run, eight chunks produced 108 batches, including solid props; no visual parity or performance claim follows.
