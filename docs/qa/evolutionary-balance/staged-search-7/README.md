The run was stopped by the experiment operator because the screening limit of 180 s `Game.tick` per day was too permissive for poor candidates; the limit was not crossed, so this is a **batch-level computational cost stop**, not a per-campaign engine error. The next short screening should use a 45–60 s/day ceiling and keep a cost stop distinct from native defeat. It must include a zero-wall investment genome and compare matched wall, no-wall-with-Shield, and no-defense controls with identical agricultural powers. This batch cannot answer whether ignoring walls is optimal, nor whether any candidate survives late nights.

This localises the cost to engine tick/navigation work rather than the policy selector or military scale; a full stack profile has not yet been run.
