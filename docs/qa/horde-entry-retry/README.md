## Retry contract implemented

Nighttime spawn returns explicit outcomes. A failed entry does not consume the night plan, allocate actor IDs, draw strike budgets, open hiring, process agricultural events or claim victory. The first attempt consumes exactly the original preferred-side RNG draw, retrieves pre-draw worker preparation first, and persists the side (including0). Successful strike-budget draw ordering is unchanged.

Retry input keys include group, side, actual camera/bounds, geometry epoch and relevant structure status. They exclude unrelated RNG after side selection. The same failed input returns immediately. A fresh prepared reply can trigger one attempt; worker lifecycle revisions are transient object identities in a WeakMap, not persisted token numbers that could collide after recreation. Worker key/request/computation understands an already selected side and draws only for the original unselected case. Stale group/camera replies remain rejected. Pending metadata is optional; old selected groups are not rerolled.
