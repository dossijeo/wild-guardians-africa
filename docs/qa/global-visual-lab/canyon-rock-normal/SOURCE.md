# Fuente reutilizada

El repositorio identifica estos mapas como Rock035 en public/content/ground-materials.json, donde ya se usan para roca volcánica. Este ensayo reutiliza esos archivos; no incorpora descargas ni modifica sus bytes.

- Fuente del material: https://ambientcg.com/view?id=Rock035
- Licencia: CC0, declarada en la página oficial consultada el 20/10/2026; https://docs.ambientcg.com/license/
- Archivos locales, hashes y dimensiones: source-audit.json. No se ha afirmado igualdad binaria con un ZIP actual del proveedor.

Adaptación de uso: proyección sobre dos ejes verticales mezclada según normal geométrica; luminancia del color modula de forma limitada las bandas cálidas existentes. El segundo piloto añade las pendientes del normal map con orientaciones coherentes con cada proyección. Sin desplazamiento de geometría ni modificación de siluetas.
