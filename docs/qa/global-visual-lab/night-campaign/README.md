# Piloto nocturno en campana

48 capturas de seis biomas, base y candidato, dia/anochecer/noche/amanecer. Semilla 712, calidad media, camara fija del asentamiento, pausa QA y reloj visual fijo. Desierto conserva 1,12; los otros cinco usan 1,55. comparison.json verifica 24 parejas con camara/objetivo/hora/dia/calidad/poblacion iguales, cero draws/triangulos extra y cero errores registrados. Contador global de texturas -7 en algunos casos entre cargas, sin recursos nuevos ni ahorro atribuible.

La mejora de lectura justifica la [integracion experimental y repeticion](../night-integrated/README.md), donde estan las limitaciones y conclusiones. Este piloto no contiene las series numericas de transicion; se capturaron despues con la version integrada.
