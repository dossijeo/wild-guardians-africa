# Fundido suave integrado en laboratorio

La preferencia del usuario sustituye el descarte artístico anterior del fundido convencional: se acepta transparencia tipo cristal antes que dithering. NativeAssetGroups activa smoothObstruction al iniciar visualLab=global-lighting. Solo las instancias de color parcialmente ocultas se separan en draws transparentes ordenables; opacas conservan agrupación, sombras conservan población. Las transparentes no escriben profundidad y no se añade la pasada opaca auxiliar que bloqueaba efectos. Se fuerza FrontSide durante el fundido. Se mantienen matrices, mallas y siluetas originales.

Diez parejas Gran Cañón día/noche (cinco posiciones): no errores registrados; cámaras y geometría comparables. En vista24, una instancia parcial añade una llamada (57→58), mismos974640triángulos. Vista36:51→51; vista47:41→42. Vistas0/12 no tienen parciales. Las capturas muestran desaparición del patrón en puntos y transparencia con capas internas todavía visibles. No se promete mejora de FPS; falta benchmark específico y validación completa de orden con efectos. La ruta fuera del laboratorio conserva comportamiento anterior. Esto no sustituye todas las transiciones de impostores ni las excepciones de clipping fuera del agrupador.

19 pruebas de agrupación/ocultación pasan, incluida separación de parciales, sombras intactas, ocultación posterior, liberación y shader sin descarte tramado para parciales. Build pasa (avisos habituales de bundles/importación mixta). Capturas reales confirman compilación con FrontSide.

Prueba adicional de árboles: ../obstruction-frontside-trees compara fundido con lados originales frente a FrontSide, Sabana baja, día/noche. Vistas0/9/17 idénticas; vista35 diferencias pequeñas (MAE .0075 día/.00177 noche). Dos instancias parciales en vistas9/17/35. Por tanto descartar caras traseras no elimina en estos modelos las capas delanteras superpuestas. Para una sola capa se requiere seleccionar la superficie más cercana del objeto en profundidad aislada o técnica equivalente, sin contaminar la profundidad de otros transparentes. Esa mejora sigue pendiente; no se presenta FrontSide como solución completa ni como culling de objetos detrás del árbol.
