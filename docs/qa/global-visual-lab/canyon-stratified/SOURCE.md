# Cliff Side — Poly Haven

Fuente: https://polyhaven.com/a/cliff_side
Licencia: CC0, https://polyhaven.com/license (verificada el 20/10/2026).
Fotografia: Dario Barresi y James Ray Cock. Procesado: Jenelle van Heerden.

Descarga mediante API publica /files/cliff_side. Mapas Diffuse JPG y nor_gl PNG a 1024 x 1024, originales sin modificar. MD5 comprobado contra la API; URLs, bytes y SHA-256 en source-audit.json. El PNG original usa mas bytes de disco que un mapa optimizado; no se ha optimizado para produccion.

El proveedor indica 1,8 m de ancho. El piloto repite cada 8 m para que las fracturas se lean a la distancia del juego. Solo se usa luminancia del color, modulando la paleta calida existente. Normales OpenGL, intensidad de pendientes 0,45. No se desplazan vertices ni se modifica la silueta.
