Se conserva el GLB original. Blender suelda vértices duplicados, recalcula normales, ajusta altura, da espesor cerrado a las hojas y aplica un gradiente de vértices seco/no metálico. No se usan planos cruzados con textura ni se alteran los modelos originales del juego. El modelo fuente usaba caras duplicadas de espesor cero; no se presenta como volumétrico antes de la adaptación. El audit del resultado confirma cero bordes abiertos y cero aristas no manifold.

Se revisó también Ultimate Stylized Nature de Quaternius (https://quaternius.com/packs/ultimatestylizednature.html), cuya página declara CC0; la descarga oficial devolvió cuota excedida. No se incorporó ningún archivo de ese paquete.
