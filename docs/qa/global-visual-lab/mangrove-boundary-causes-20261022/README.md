# Leaf boundary cause audit

Read-only QA instrumentation of actual continuous-grass candidate rejection, original dense Mangrove recipe, seed712/media/full far world. Paused before first game frame, normal camera. Run audit-mangrove-boundary-causes-20261022.mjs then plot-mangrove-boundary-causes-20261022.py. Instrumentation repeats some calculations: timings are invalid for performance conclusions.

16,640 unique cached candidate positions: 6,360 accepted; 9,265 fail wear, 830 water, 1,276 object footprint, 12 cover, zero slope. 1,288 have multiple causes, so counts are not additive. Another 185 fail footprint wear reach after initial exclusions. 4,584 instances selected for drawing. Cache perimeter is rectangular by construction and is not the screen-space perimeter. The prior 8,119 cached-root audit had a different preparation history; do not interpret its count as density regression. Current selected near/far counts match that audit (1,743/2,841).

The dominant exclusion around the clearing is settlement wear. Source spatial-savanna.cpp computes radial clearing plus axis-aligned paths with small warp. An apparent chunk-boundary cut in the cached plot prompted checking overlapping native mask samples: all 3,768 shared world positions have identical RGBA values, no seam inconsistency. Do not attribute this to a native chunk mask seam.
