# Worker-precomputed sky palette for reflections

Both variants retain the selected sky cloud latitude and matching day reflection latitude. Candidate additionally grades the256x128 environment texture once in the sky preparation worker: average original RGBE radiance as before, expose, apply the same saturation/cloud-protected daytime palette or night tint as visible sky, invert the display exponential to exposed radiance, and apply the existing environment compression. No change to water/material BRDF,film curve,environment mipmaps or samples. The inverse is bounded at display white (1e-6 residual). This is artistic radiance reconstruction, not recovery of physically measured illumination. Filtering before nonlinear grading remains an approximation. Procedural visible stars are not baked into the reflection map; existing night fill remains.
