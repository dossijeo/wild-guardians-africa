# Ondas normales de charca: descartadas

Segundo brazo del [estudio de escala de ondas](../pond-wave-scale/README.md): pintura original, normales de longitud menor. A cámara baja genera franjas de reflexión demasiado regulares. Se conserva la evidencia negativa, sin cambio runtime ni ABBA. Este directorio contiene las 16 capturas WebGL, auditoría de materiales y comprobación de cámaras/recursos.
