# Ondas sinusoidales cortas — no adoptar

16 capturas de Sabana y Gran Río, cámara de juego/baja, día/noche. Normales de onda de menor escala, menor mezcla del dibujo original y algo más de reflexión. Sin mapas, geometría ni draws nuevos.

Las bandas anchas pierden peso, pero el relieve sigue siendo débil en la vista de juego. No justifica una incorporación aislada. La siguiente prueba separa la base cromática de la reflexión. No se midió GPU de este candidato.
