# Resident ground mask lifecycle and review selection

2026-10-25. Sabana and Manglares, seed 712, populated paused scene, 720p, initial media, pthreads, scheduler, retained programs. Actual quality sequence media/baja/media/baja followed by forced WebGL loss and restoration. The QA helper reads the compiled material uniforms (Three r180 private properties, read-only, QA only), checks all 64 mask cells against installed visible chunks, and then repeats after quality/context changes.

Both cases pass: 25 resident cells, 256-byte source payload, stable texture identity/version across the sequence, unchanged world snapshots, live draw calls after restoration, no GL error. Sabana native memory 16 MiB; Manglares 16 MiB. Recorded program recovery scope approximately 1.184 s and 1.307 s respectively; these are NOT frametime or complete recovery latency benchmarks. Compiler X4000 warnings remain in raw reports; no other logged errors.

Manglares screenshots after-quality and after-context were visually inspected at the same final baja setting: ground, localized mud and fern mass remain visible. The initial before screenshot is media, so it must not be treated as an identical-quality pixel reference. Sabana has telemetry only for this pass. A stale context-lost warning remains displayed in the Manglares restored screenshot despite the verified removal of the context-lost pause. This UI issue is observed and remains unresolved; do not claim flawless overall recovery UX.

Decision: enable groundResidentMask=1 in the current artistic review recipe for Sabana, Gran Rio, Manglares and Volcanes. Normal game defaults are unchanged; Desert/Canyon use another horizon representation and are excluded. This adopts the coverage improvement verified in earlier day/night movement captures plus stationary cost and these lifecycle checks. It is not a claim that every height seam is solved. Internal missing-chunk boundaries still lack their own height bridge, and stationary cost does not characterize worst-case fallback rasterization.

Reproduce the lifecycle by running check-spatial-thread-game.mjs with WG_CURRENT_REVIEW=1, WG_THREAD_PORT=5190, WG_THREADS=1, WG_THREAD_FROZEN=1, WG_FRAME_SCHEDULER=1, WG_THREAD_RETAIN_APP=1, WG_THREAD_QUALITY=media, WG_GROUND_RESIDENT_MASK=1, WG_GROUND_RESIDENT_LIFECYCLE=1, and WG_THREAD_BIOME=sabana or manglares. Set WG_THREAD_REPORT to a fresh output path. Verify retained JSON with summarize-resident-mask-lifecycle.py. No gameplay logic was changed.
