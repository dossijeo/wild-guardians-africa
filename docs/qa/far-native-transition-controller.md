# Controlador experimental: cobertura nativa + preparación GPU

FarTreeTransitions conecta NativeTreeCoverage con setTreeReadiness/setTreeEnabled del prototipo. El caller debe acreditar preparación real de texturas/programas GPU antes de pasar gpuReady=true. El módulo no deduce esa condición a partir de una solicitud o de matrices CPU y no implementa todavía compileAsync/precarga en WorldScene.

bind restaura por ID, con estado inicial0 para árboles nuevos. setCoverage combina cobertura por instancia nativa empaquetada, bandera GPU y ausencia de supresión. Solo entonces empieza rampa0→1 (duración configurable). Pérdida de cobertura/GPU devuelve inmediatamente el impostor. setSuppressions oculta ambos brazos, cancela transición y permite volver a preparar al restaurar. advance recorre únicamente IDs con una transición activa; después de alcanzar1 no envía cambios. Revisiones de cobertura evitan recorrer árboles en frames quietos; supresiones iguales no actualizan. Estados de IDs fuera de región y sin cobertura se retiran al actualizar, para no conservar indefinidamente preparación obsoleta; supresiones lógicas continúan independientes.

Pruebas con createAssetLod/updateAssetLods/refreshResidentProps reales y buffers de createFarImpostorPrototype: chunk instalado count0; matrices listas pero GPUfalse (sigue0); GPUtrue y avance.5 (ambos atributos.5); supresión (ambos-1), repetición sin escrituras, restauración y preparación completa. Migración reordenada conserva .25 del ID compartido. Retirada de chunk y pérdida GPU mantienen fallback. 180 consultas estables no producen escrituras adicionales. Datos inválidos de tiempo/GPU se rechazan y clear libera referencias.

Este lote no tiene captura ni ejecución WebGL: acredita conexión CPU y buffers, no compilación/subida real ni frametime. Tampoco acredita crossfade en batches de color nativos/NativeAssetGroups, render-origin, sombras, culling, guardado o todos los biomas. El juego activo aún no usa el controlador. Próximo paso: preparación real de recursos y fade de los batches nativos (incluida su agrupación), antes de integrar el paisaje lejano.
