# Isolated single-exit noise control

QA-only `FineNoiseVolume({singleExit:true})` initializes a scalar, assigns it in
the same mutually exclusive analytic/texture branches, and returns once. The
threshold, noise argument, texture coordinates, smoothing curve and number of
texture/analytic calls are unchanged. The default retains the early-return
body. Program keys distinguish the control. No production imports or activation.

Twelve noise/depth tests pass, including byte equality outside the generated
helper, the single-return structure, exclusive source calls, program keys,
uniform sharing and existing depth-hook checks. The edited fixture module passes
`node --check`. Five full intensive-policy tests also pass on current production
code: ordinary expansion/paid delivery, recorded economics, paid mid-day hiring
and both bad-management defeats. Those tests are separate from shader QA and do
not establish the 100-night matrix.

Native tab 666 used Vite 5183, Volcanes/Mapungubwe, seed 712, medium quality and
shadows with `case=16&noise-volume-single-exit=1`. Four captures cover both noise
branches at day/night, reporting the same camera/target and 48 adapted programs.
The tab was closed after export. Four campaigns and the policy suite were CPU
background work; no render timing was collected.

The earlier tab 665 logged five ANGLE warnings naming both `f_environment4` and
`f_volumeFineNoise`. This control logs five naming only `f_environment4`. The
noise return warning is absent in this sample; the HDR warning remains. This
does not prove a genuinely uninitialized value, a driver root cause, a speedup
or correctness on other GPUs.

Full screenshot comparison against the earlier tab (921,600 pixels per image,
no alignment or masks): analytic day differs at 34 pixels (max 2/255); texture
day at 336 (max 22/255); both night pairs are exact. Separate-tab captures have
no repeated-native control, so daytime differences cannot be attributed solely
to this change and exact framebuffer equivalence remains unproven. Visual
review shows coherent silhouettes and colors in this camera, not broad visual
acceptance.

The noise volume and return control remain outside gameplay. Continue with
paired native controls, periodicity/distance, biomes/cultures, damage/poses,
performance and physical mobile before deciding whether to integrate.
