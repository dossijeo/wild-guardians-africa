# HDR return control-flow experiment (not production)

Current native scene logs sometimes contain ANGLE HLSL warnings for f_environment4 and f_volumeFineNoise. The corresponding GLSL has returns on every path: this inspection does not identify an uninitialized GLSL local or establish an image bug. volumeFineNoise is an experimental test-only adapter, absent from production. environment4 has guarded day/night endpoint returns and an unconditional original mixed return.

A source-only QA control (HDR salida unica (QA) in african-toon.html) rewrites only the received HDR body to an initialized result, exhaustive if/else and one final return. UVs, LOD, sampler scale, endpoint conditions, night fill and original mixed recipe remain unchanged. Production shader imports are untouched. The volume adapter is unchanged so the two warning sources can be separated. Toggle recompiles the current material set with a distinct program key; it is not a moving-world implementation or performance optimization.

Offline inspection: both authored environment sources (environment-only and painted fluids) round-trip exactly by reversing the one replacement, with idempotent adaptation. Eleven directed tests pass: baseline endpoint/reflection/noise plus byte-preserving adaptation and reversible material hooks/cache keys. This is source transformation evidence only. Native comparison, compiler diagnostics, pixel equality, day/night/intermediate/extrapolated phases, endpoint switch and GPU measurement are still required before considering any runtime change. No claim of eliminated warnings or reduced frametime.
