# Young maize shared reverse candidate

This is an isolated candidate, not a production asset or category approval. The
DoubleSide forward version was screened in native views 915 and continuity
923/924. Those observations do not approve this FrontSide recipe or its cost.

The reproducible Blender reduction retains all 936 core triangles and simplifies
the seven labelled leaf surfaces to 159 triangles. The native writer shares the
1921 position/normal/UV vertices and appends reversed leaf indices. The resulting
1254 triangles equal the original young mesh's triangle count. No camera masks
choose faces. The original growth bridges, pivots, materials and wind recipe are
retained. Native bridges remain original during transitions; only the young
original phase receives the override.

Three colour groups draw core, leaf fronts and leaf reverses with FrontSide and
the original DoubleSide shader definition. The reverse group changes facing
orientation in the shader to preserve the source lighting recipe. Shadow depth
remains DoubleSide for this first isolation. It does not establish FrontSide
shadow acceptance. CPU shader string checks do not establish successful native
compilation, culling or visual fidelity.

`front-runtime-contract.json` records 66 native batch updates over incoming and
outgoing young growth seams. Matrix, growth, bridge, count and visibility inputs
match the four arms; borrowed attributes survive release. Geometry uses 68996
bytes versus 75748 source bytes (-8.91%). Referenced vertices summed per draw
group are 2236 versus 2132 source references (+4.88%). That is an invocation proxy,
not measured shader executions. Additional material groups and resident original
buffers must be included in subsequent resource and GPU measurements. Neither
the mature maize GPU benefit nor a reduction in geometry bytes approves this
candidate's net cost.

groups. These GL state reads are instrumentation outside any timing campaign.
The report requires FrontSide, enabled BACK culling and the explicit original
DoubleSide shader definition when the young override is active. A source material
without an explicit definition can still receive Three's generated DoubleSide
definition; the witness field records the explicit property only.

Visual acceptance policy 3 prioritizes convincing recognizable maize, preserved
leaves/form/growth and absence of perceptible defects in real gameplay. Numeric
metric policy 2 remains diagnostic and never automatically rejects a view. Root
AI inspection is recorded separately from human-user approval. Remaining gates
include independent angles, growth seams with this FrontSide recipe, wind,
effective shadows, functional compatibility, resident resources and net World
GPU benefit. No native FrontSide screen has been accepted at this freeze.
