# Paired GPU experiment planned after appearance review

No benchmark is authorized as an acceptance result by this document. First inspect the fixed derivative at real gameplay distance, night/day, growth transitions and effective shadows; record any perceptible defects. Pixel diagnostics alone do not determine that decision. Preserve sources, shader recipes and geometry hashes before performance dispatch.

Four measured arms must use the same plants, terrain, camera, light, wind clock and native passes: original Double, indexed original Double control, reduced shared forward geometry Double, and the same reduction plus shared geometric reverses with FrontSide color. This separates indexing, reduction and culling/draw-group costs. The body/terrain/other crops must not be reclassified silently. The original forced-Front ceiling is background evidence, never the candidate baseline or an inherited saving.

Start with a reproducible representative mature maize lot, record exact plant count and active stage/bridge counts, and then test a mixed dense WorldScene for dilution. Inactive geometry allocations still count towards memory. Report color, native depth and shadow submissions, texture/program/buffer allocations, actual original-plus-candidate coexistence and standalone allocation separately. ShadowSide/customDepth must be captured from effective draw materials; the current visual fixture isolates Double shadows and cannot establish a complete shadow adaptation.

Use valid EXT_disjoint_timer_query_webgl2 GPU queries, warmup120 frames,300 samples per arm and six paired AB/BA comparisons, with disjoint samples excluded and counts retained. Fresh process inventory and coordination with root/loading are required; no own Blender, suite, other scene or unrelated benchmark during measured windows. Historical campaigns may remain live and must be declared. Record resolution/context attributes, source/candidate/fixture hashes, active lights/shadow maps, renderer draw counters and sustained conditions.

The existing net performance gate remains median improvement at least5% and0.20ms, paired95% confidence interval above zero, p95 regression at most2% or0.1ms, and mixed-world regression at most2%. Do not infer improvement from nominal triangles, cache simulations, CPU submission time or one favorable block. If three-group overhead cancels the reduction/culling benefit, retain that negative and revisit the asset or batching design rather than claiming the original ceiling. Whole category, bridge, web bytes and measured peak GPU memory budgets remain requirements before integration.
