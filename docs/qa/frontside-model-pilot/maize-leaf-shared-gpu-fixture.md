Color recipe is source Double versus three Front groups with preserved Double shader and explicit source-back recipe. Shadows/customDepth remain Double isolation. The experiment measures this partial adaptation including its extra shadow submissions; it does not establish Front shadow correctness or full mixed-world benefit.

Timing campaign uses six prospective paired AB/BA comparisons,120 unqueried warmup frames per block and300 submitted elapsed queries per block:5040 drawn frames total. The elapsed query brackets native sky draw plus scene render (current native shadows and color), excludes JavaScript polling, and retains raw native frame identifiers/results. Pending queries are drained for at most240 animation frames without another draw. Any invalid/disjoint/lost/overflow/foreign/allocation condition stops collection without reroll and is preserved. The paired analyser retains the previously published performance thresholds and cannot establish category acceptance. Polling/progress UI and historical CPU campaigns remain limitations; fresh authoritative inventory and exclusive GPU window are required.

Resource campaign performs no elapsed queries. BUFFER_SIZE hooks are installed before renderer allocation, then snapshot before draw, after120 original frames, and after120 candidate frames. This measures observed WebGL buffer storage and coexistence, not driver physical residency. Texture/program/renderbuffer metadata and renderer counts are reported separately; hypothetical standalone deployment must not be inferred by subtracting coexistence snapshots casually. Four CPU rigs exist in both campaigns; only original0/candidate3 are drawn.
