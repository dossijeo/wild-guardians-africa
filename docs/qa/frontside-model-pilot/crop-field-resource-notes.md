# Field reconstruction resource checks

The read-only header inventory completed with exit 0 (2.54 seconds). The original and compressed runtime crop GLBs each contain two authored material atlases. Each atlas uses a 2048×2048 base-color image, a 1024×1024 normal image and a 1024×1024 metallic/roughness image. Runtime images are WebP; originals are PNG/JPEG. The script records image hashes and material-to-texture indices. It neither decodes pixels nor changes files.

`crop-batch.js` clones the materials, retains base/normal textures, sets normalScale to (.48,.48), and clears metallic/roughness maps. A complete RGBA8 mip-chain *hypothetical* bound is 22369620 bytes per base-color image and 5592404 per normal image: 55924048 bytes for the two base/normal atlas pairs. This is not observed resident memory: format, sharing, mip upload, cache ownership and other rendering allocations must be measured. The metallic/roughness image headers must not automatically count as an additional crop-batch GPU allocation when those maps are cleared.

The archived mature draft's 391914 decoded NPZ bytes also are not a deployed GPU representation. Field reconstruction would need original position/normal/UV values, source face indices and a lookup domain. Packing every triangle's three corner fields independently would duplicate many source vertex values. Packing original vertex fields once and indexing them avoids that duplication but adds domain/lookup storage and shader fetches. Keeping original GPU geometry simultaneously with a texture copy of the same fields must count both allocations. Releasing a runtime buffer requires explicit ownership and bridge-preservation evidence, not an assumption that the source model is no longer needed.

Before a candidate benchmark, report complete-category storage, original versus candidate upload/residency, lookup tables, geometric buffers, draw submissions and source/candidate coexistence in QA separately. The 5% GPU memory and 10% decoded-byte gates remain. The extra field reads, per-fragment growth and primitive-local derivative reconstruction may erase the original forced-Front ceiling; only a paired net benchmark can resolve that. No current geometry draft has a complete field shader or resident-memory measurement.
