# Tinify wall atlas integration

The native Bastion atlas is reduced from 1,333,473-byte JPEG to 512,750-byte WebP: 820,723 bytes saved (61.55%). Both are 2048×2048 and opaque; decoded alpha is identical. RGB is lossy (mean absolute difference 3.8845/255). Tinify's pilot report retains acceptedForRuntime:false as the earlier-stage record; this follow-up accepts the variant within the scope below. Original bytes remain in Git outside the shipped package.

The image-runtime alias applies to the shared wall material; all native UVs, sampler settings, shaders, region bridges, destruction geometry and gates remain unchanged. No extra samples, rescaling or color-space changes. Native render tests use the original WorldScene/NativeWall renderer in Sabana/Mapungubwe, seed 712, medium quality at 1600×900. Five materials (thorns, wood, adobe, reinforced, stone), walls and opened gates appear together. Four HP ratios (1,.75,.35,0) are compared in daylight and night against direct canonical original and candidate URLs: 16 frames, identical camera, zero reported shader errors. No evident material discontinuity or loss of silhouette in these views. This does not establish all angles/biomes/mobile/Windows acceptance.

QA reproducer: tests/browser/african-toon.html?case=1; “Ver atlas de murallas (QA)”, “Murallas Tinify / original (QA)”, “Estado murallas (QA)” and “Día / noche”. The toggle checks actual image URLs and updates native prototypes and existing wall material clones, so regenerated damage stages retain the selected texture. It invalidates shadows for comparison and cleans up the original texture with the fixture. This comparison requires source assets deliberately absent from dist.

All 16 screenshots are lossless WebP encodings of native captures: decoded RGBA compared byte-equal; hashes in screenshots.json. Source PNGs retained locally in .cache/tinify-wall-screenshots. Browser logs preserve one ANGLE warning for potentially uninitialized f_environment4/f_volumeFineNoise, not fixed or attributed to this compression; no shader error.

42 directed tests pass (runtime image hashes/dimensions/alpha/relative contexts plus native wall pivots, stages and destruction). Build succeeds in 11.56 s with existing bundle-size warning. Package verifier: 587 files, 378,818,303 bytes, 859 relative references, 20 runtime GLBs, no replaced originals. Prior package 379,637,798 bytes; net reduction 819,495 bytes. Encoded size evidence does not demonstrate GPU-memory, frame-time or loading-time gains. Broader images/embedded textures remain pending.
