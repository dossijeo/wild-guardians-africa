# Pinned native loading capture launcher

`tools/run_native_loading_visual.ps1` generalizes the already exercised7e saved-night launcher. Supply the exact executable/source and fixture SHA256, a new output directory, and `Capture`=`initial`, `plant` or `plant65`. Resolve the source/executable association against original GitHub artifact metadata first: the supplied source ID is provenance recorded by the operator, not something the launcher can recover from an arbitrary EXE.

The launcher uses one owned hidden process and a fresh WebView2 profile; rejects digest mismatches, existing evidence and another game process; retains the original report and receipt; restores the prior process-local profile variable and only terminates its own process on failure. The900000ms fixture watchdog is unchanged. This does not change the engine's90000ms readiness or300000ms hidden checks. No trace/overlap/selection flags are added.

The executable must contain the explicitly reviewed visual collector and corresponding CLI guards. Production025 alone does not install the collector. Captured runs include PNG readback/encoding overhead and cannot serve as loading-performance benchmarks. A successful report still needs actual frame extraction and inspection; it does not prove physical input, composited HTML, portrait or all-biome coverage.

PowerShell AST parsing passes. The real Windows preflight test exercises incorrect executable/fixture digests and preservation of existing evidence using a deliberately inert non-executable file: all three reject before launch. Its first attempt exposed inherited PowerShell Core module paths in the Windows PowerShell child (`Get-FileHash` unavailable), rather than an executable/game failure. The test now supplies the system Windows PowerShell module path to that child; its directed rerun passes. Actual game launch with this generalized tool remains pending. Report field checks were matched against the retained original7e report (`beforeCount`, `afterCount`, `startProgress`, `progress`), not inferred from conversational shorthand.
