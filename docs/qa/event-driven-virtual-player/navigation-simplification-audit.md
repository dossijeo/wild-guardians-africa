# Navigation simplification audit — 13 October 2026

The current experimental stack has four different answers to whether an animal can reach a crop: native `approachReachability` and `approachGroupBlocked`, the independent connected-component flood in `shared-connectivity-prototype.mjs`, the shared route tree in `enclosure-route-tree-prototype.mjs`, and the final per-crop ring in `reachableApproach`. The second and third answers traverse the same logical-grid cells. `region-goals-tree` invokes both, while uncertain answers can still invoke the original 32-point ring. `closedRegions`, `searchedRegions`, and failed-endpoint memoization inside native navigation add further work during fallback. Portal width classification is topology-versioned and reused; it is not responsible for the measured component traversal.

The matched Sabana seed-123 14-night control accumulated 115.1 s in `Game.tick`. Full regional components accumulated 173.1 s, including 62.5 s of component traversal. A probe before building the component lowered that traversal to 24.6 s, but total `Game.tick` remained 167.2 s. These campaigns have different physical paths and farm trajectories, so the totals measure practical sustained cost, not same-state algorithm speed. The Sabana day-12 and Canyon day-7 checkpoint replays hold the input state fixed and separate the local navigation cost.

The smallest architectural candidate removes the independent component flood from the active QA mode. The shared tree's existing cost array is the connectivity evidence for the selector; only a few target service points and native-validated local connectors are considered. The route tree continues to reuse its frontier and the existing species-specific breach portals. If the tree is incomplete or its finite boundary was reached, the selector does not certify a negative path; it uses the native fallback. This is slower at a Canyon closed-farm checkpoint than the component prototype, but preserves the no-false-exclusion rule. A future replacement must express closed-region evidence directly in the shared grid or portal graph without introducing another full actor-side exploration.

The old QA modes remain available solely to reproduce negative results. They are not layered into the new mode. No production navigation mode has changed. Promotion requires a sustained 14-night gain below the 115.1 s control, physical-route and save/reload checks, and then progressive 30/60/100-night campaigns. Checkpoint speed alone is insufficient.
