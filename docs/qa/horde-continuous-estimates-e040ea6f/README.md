## Algebra and meaningful margins

Let I be recorded average paid income; S seeds, W wages; y aggregate realized payout scale; V(y)=replacement seed+payout*y*lost-harvest fraction. For each arm, incremental crop deaths K above the retained baseline give:

`NetGood = (I-Kg*P*loss)*y - (S+W+Kg*seedUnit+repair+defense)`

`NetBad = (I-Kb*P*loss)*y - (S+W+Kb*seedUnit)`.

For positive coefficients Ag/Ab, responsible goal+500coins/day, neglect goal-500coins/day and rounding allowance R:

`lowerY=(Cg+500+R)/Ag`; `upperY=(Cb-500-R)/Ab`.

The open interval exists only if lowerY<upperY. Coefficient signs are checked; zero/negative cases are not silently divided with the wrong inequality. Foregone harvest is opportunity cost, never a fake ledger payment. Repair estimate is conditional timely paid HP restoration, not proof that workers can arrive.

R353 covers the original peak303 daily paid deliveries plus approximately50 hypothetical positive repair settlements, allowing less than1coin ceil discrepancy per operation. Both counts can change with the candidate; this is an explicit retained-peak/stationary repair allowance, not a guaranteed future bound. Base crop prices must themselves be mapped upward to integer coins and the weighted effective y recomputed before any pilot. No fractional visible currency or free rounding gain is proposed.
