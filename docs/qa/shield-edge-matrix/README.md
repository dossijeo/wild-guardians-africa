# Shield edge matrix on original terrain

The fixture `tests/browser/shield-edge-matrix.html` covers six native biome generators and five original bestiary rigs with seed 712 and Mapungubwe. It purchases a real work centre and uses the unmodified position selected by production `spawnRaid`; neither terrain, vegetation nor animal position is replaced by a flat laboratory arrangement.

The night, raid composition and sampled clip phases are controlled diagnostics, rather than a natural campaign. Each native clip is applied by the production animation mixer at phases 0.1, 0.5 and 0.9. Placement is tested 3 cm inside and outside the sum of the authored animal body radius and Shield radius. The inner cast must reject atomically. The outer cast uses a cloned game state with the same production Navigation and must leave the animal in its original position, with duration 20 and cooldown 90. Navigation is then rebound to the displayed state.

The screenshots show the actual rendered model and production placement preview; the JSON files retain all sampled contract results. These are not screenshots of committed Shield VFX or proof of every attack pose's full silhouette. Native vegetation can partially occlude a model. The radius is the established body navigation cylinder sampled from Walking/Running, excluding shoulder/arm/hand and decorative weapons; attack clip rendering does not redefine that collision contract. No animal scale is changed (1,1,1).

This directed matrix complements the five-species approach/expiry/navigation tests and the original-terrain warthog expiry walkthrough. It does not replace campaign, sound, or device performance acceptance. The three approved powers remain Shield, Growth and Multiply; no Repulsion behavior is added.

Results: all 30 cells and 558 clip-phase contracts passed; all 13 focused spell-preview/Shield-expiry tests passed. `validation.json` records the dimensions and production commit. Camera inspection angles changed during the run; captures retain their actual views.
