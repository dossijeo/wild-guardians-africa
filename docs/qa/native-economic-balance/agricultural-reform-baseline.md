# Historical baseline before single-plant agricultural magic

The q8 seven-night controls (123, 2026 and 712) and maintained-defense pilots
record the previous area/cooldown agricultural magic economy. They are retained
for comparison, not acceptance evidence for the newly requested magic reform.

The maintained-defense 2026 run stopped cooperatively during day 7 (six complete
daily rows). Its receipt and partial state identify a diagnostic CPU stop, not
an economic defeat. All other newly retained seven-night runs completed.

`perimeter-proof-cache-diagnostic/result.json` compares cached and uncached
predictive navigation checks on that preserved state, in AB/BA order. Results
and input state are identical. This measures a QA-planning CPU optimization;
it does not measure gameplay GPU performance or full-campaign loading time.

No definitive calibration resumes until single-plant agricultural magic is
integrated and campaign policies and activity observers are updated.
