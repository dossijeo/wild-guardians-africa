# Native hostile gate-phase invariance matrix

Performance precondition for the opt-in QA animal certificate cache. The live campaign and default gateAnimationInvariant=false are unchanged. This is not a new balance candidate, policy, or production optimization.

The first fixture attempted to purchase a gate without an operational center and correctly failed all 30 cases at permission checking. Negative output is retained. The corrected fixture uses createOpeningWorld for a native legal village and normally paid 800-coin center. It searches unchanged native terrain for legal gate placement and purchases an empalizada gate using the real command and ledger. No artificial funding, terrain overrides, radius changes or teleportation. Controlled gateOpen phases are diagnostic inputs, not animated movement.

Thirty combinations: all six biomes and all five cultures, seed 712. Each checks the distinct presentation radii of all five native animal species at phase 0/.25/.5/.75/1. Native navigation setState is called after every phase, so stale obstacle/cache state cannot conceal a dependency. Gate-center walkability and two perpendicular swept crossing segments remain blocked and exactly identical across all phases. Every query preserves serialized paid state.

All 30 pass in ~35.86 seconds on this run. This specifically certifies empalizada static hostile gate footprint invariance on the sampled layouts; it does not certify all closed perimeters, all materials' dynamic worker paths, all seeds or complete campaigns. Existing material/worker and real wall-removal cache regressions are run separately. The earlier AB/BA speed result remains a local QA query benchmark, not a whole-campaign measurement.

No proof shortcut is enabled for live workers: their service proof and animated gate clearance continue to run freshly. No running campaign is patched. Broad CI, source-frozen performance comparison and native balance acceptance remain required before any new campaign protocol is approved.

Separate gate/worker/material/cache regression selection: 36 pass, zero failures/skips (~32.50 seconds). It includes native wall removals invalidating a previously positive certificate and rejection of customized physical adapters.
