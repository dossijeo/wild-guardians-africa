# Funded day-seven service proof: positive-component reuse

This experiment changes only the campaign defense policy's geometric proof, not the game simulation, animal routes, prices, defenses or agricultural rules. It remains on `codex/campaign-unfunded-geometry-guard`; it is not a completed hundred-night campaign or balance acceptance.

The frozen native day-seven state (Sabana / Mapungubwe / seed 123, Q15 good policy) was captured before the first funded wall decision at day time 36 s. It has 449 coins, 181 live crops, 12 hired workers and 33 paid wall pieces. The remaining proposed contour costs 450 coins. The state and policy are retained as `day7-funded-state.json.gz` (SHA-256 `022fdfd29597a4fc445bea6af5a1b0c6c0f41dbc804d9e04f533fbbf4559a5a3`) and `day7-funded-policy.json.gz` (SHA-256 `84fa0ec64afd68247f105b3cd55eb2aa3a718d33fef4d2400c230dfae31259e3`). This is a diagnostic mid-day snapshot, not a save-slot promotion.

On this state, the native wall quote takes about 87 ms and yields 45 proposed pieces plus one update. The expensive stage is `nativeServiceComponentProof`: it tests 32 physical attack positions per target for each of five animal radii. The existing path search has already produced positive closed-region certificates. Repeating full A* at every position cost roughly 17–20 s for the five-species proof. The candidate skips that repeated search only when `Navigation.approachRegionBlocked` positively certifies all native origin connectors around the pose. Direct physical segments, crop contact rays, full A* fallback when no positive certificate exists, and the subsequent complete enclosed-component checks remain in place. Animal navigation uses no worker gate portals for these queries.

The committed replay command is `node tools/experiments/benchmark-service-proof-certificate.mjs`. It reconstructs the identical proposal and compares the unmodified proof from commit `84c6ad77` (A) with this candidate (B), in AB/BA order. Before committing the harness, an equivalent local replay produced A=19,900 ms, B=9,726 ms, B=9,838 ms, A=20,378 ms. The five per-radius result objects match exactly on all four arms, all five reject outside access, and the serialized native state remains unchanged. These are isolated CPU proof times, not whole-campaign duration, frame time or GPU measurements. The focused service/contour/funded-policy suite passed 21/21, including a case that forces the full A* fallback without a positive certificate.

The prior unfunded day-nine guard remains a separate optimization. A complete native seven-night replay is preserved in `pilot-v114-certificate-good-sabana-123-seven/`. It used the same Sabana / Mapungubwe / seed 123, Q15 good, cashflow crops, shore defense from day 6, breach-first repairs and rolling funding as the frozen v111 attempt. It finished normally with seven nights, no native defeat, 731 coins and 176 live crops. All seven full daily JSON rows match the retained v111 prefix byte-for-byte, including day 7's 450 paid wall coins. The run began at 17:32:24 UTC and finished at 17:37:14 UTC, about 4 min 51 s of wall time. This is a complete short replay, but still too costly to extrapolate to a hundred nights. The older interrupted short pilot exceeded six minutes of active CPU on day 7; machine load differed, so this is not a controlled full-campaign speedup ratio. The runner still emits legacy inactivity fields; they are retained as raw evidence but are not used as a balance criterion following the user's decision to stop measuring inactivity.

Profiling the same frozen day-seven service proof after that run found 4,039 certified attack poses for the first animal radius. Although the existing native certificate proves that every walkable 3×3 origin connector belongs to one closed component, the proof still checked every physical connector independently: 37,611 `segmentClear` calls and about 1.68 s for that radius. The second candidate keeps the direct-route check and requires one actual clear body-width connector, then uses the positive native certificate to establish that all other walkable connectors belong to the same enclosed region. Without the certificate it retains the full path and connector checks; without a physical connector it still rejects the proof. The focused suite now passes 22/22, including both fallback and no-connector cases.

On the identical frozen proof, first-radius `segmentClear` calls fell to 8,506 and measured time to 0.54 s. A fresh AB/BA replay across all five species produced A=17,005 ms, B=2,591 ms, B=2,643 ms, A=21,093 ms. All per-radius proof objects remain exactly equal and the serialized game state is unchanged. These are isolated CPU measurements, not yet a whole-campaign gain.

The second complete native seven-night replay is preserved in `pilot-v115-connector-good-sabana-123-seven/`. It ran on the same seed, strategy and game rules and finished normally at 17:44:32 UTC after starting at 17:42:46 UTC: about 1 min 45 s of wall time. All seven daily JSON lines match the v114 run byte-for-byte, including the day-seven money, crops, damage and actual wall spending. The source-provenance file identifies the changed proof code; no economic, magic or raid parameters changed. The previous v114 run took 4 min 51 s, but these whole-run measurements were sequential rather than randomized AB/BA and are not a hardware-independent speedup ratio. The controlled isolated AB/BA plus exact native daily replay support retaining this candidate.

Do not yet accept a hundred-night campaign from seven nights alone. A 14/21-night pilot should check how proof cost scales as crops and walls accumulate, then the hundred-night campaign can be attempted with cooperative stopping and preserved source hashes if the longer pilots remain tractable.
