# Funded day-seven service proof: positive-component reuse

This experiment changes only the campaign defense policy's geometric proof, not the game simulation, animal routes, prices, defenses or agricultural rules. It remains on `codex/campaign-unfunded-geometry-guard`; it is not a completed hundred-night campaign or balance acceptance.

The frozen native day-seven state (Sabana / Mapungubwe / seed 123, Q15 good policy) was captured before the first funded wall decision at day time 36 s. It has 449 coins, 181 live crops, 12 hired workers and 33 paid wall pieces. The remaining proposed contour costs 450 coins. The state and policy are retained as `day7-funded-state.json.gz` (SHA-256 `022fdfd29597a4fc445bea6af5a1b0c6c0f41dbc804d9e04f533fbbf4559a5a3`) and `day7-funded-policy.json.gz` (SHA-256 `84fa0ec64afd68247f105b3cd55eb2aa3a718d33fef4d2400c230dfae31259e3`). This is a diagnostic mid-day snapshot, not a save-slot promotion.

On this state, the native wall quote takes about 87 ms and yields 45 proposed pieces plus one update. The expensive stage is `nativeServiceComponentProof`: it tests 32 physical attack positions per target for each of five animal radii. The existing path search has already produced positive closed-region certificates. Repeating full A* at every position cost roughly 17–20 s for the five-species proof. The candidate skips that repeated search only when `Navigation.approachRegionBlocked` positively certifies all native origin connectors around the pose. Direct physical segments, crop contact rays, full A* fallback when no positive certificate exists, and the subsequent complete enclosed-component checks remain in place. Animal navigation uses no worker gate portals for these queries.

The committed replay command is `node tools/experiments/benchmark-service-proof-certificate.mjs`. It reconstructs the identical proposal and compares the unmodified proof from commit `84c6ad77` (A) with this candidate (B), in AB/BA order. Before committing the harness, an equivalent local replay produced A=19,900 ms, B=9,726 ms, B=9,838 ms, A=20,378 ms. The five per-radius result objects match exactly on all four arms, all five reject outside access, and the serialized native state remains unchanged. These are isolated CPU proof times, not whole-campaign duration, frame time or GPU measurements. The focused service/contour/funded-policy suite passed 21/21, including a case that forces the full A* fallback without a positive certificate.

The prior unfunded day-nine guard remains a separate optimization. A complete seven-night replay is still needed to establish whether the funded day-seven decisions now finish in acceptable wall time and match the frozen daily evidence. Do not launch or accept a hundred-night campaign on this isolated benchmark alone.
