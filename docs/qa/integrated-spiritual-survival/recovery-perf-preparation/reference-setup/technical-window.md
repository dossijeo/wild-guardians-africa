It never changes economic/military parameters, policy decisions or configured campaign horizon.

Process exit zero for the deliberate observer stop is not a game victory.

Two unit tests verify callback ordering, unchanged policy/horizon, deliberate stop classification, invalid limits and propagation of technical errors. Their stub verifies the wrapper only and is not native campaign evidence.

Performance observations include initialization, native simulation and evidence collection; they do not measure GPU/render FPS or physical-mobile behavior.
