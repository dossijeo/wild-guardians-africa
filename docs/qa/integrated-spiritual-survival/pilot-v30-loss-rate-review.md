Read-only audit of the five terminal Q9/HP1 fourteen-night campaigns. For nights
6–14, weighted loss fraction is sum(native crops destroyed)/sum(native live
crop census at incursion spawn), not the mean of per-night percentages.
The reference curves are exposure-weighted with the same census. Neither curve
is applied to crops; every loss remains a native physical impact.

agricultural event is counted as attack damage. Introductory nights are omitted.
