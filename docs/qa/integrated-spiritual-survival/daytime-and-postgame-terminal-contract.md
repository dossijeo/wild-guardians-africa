# Native terminal audit: daytime incursions and peaceful postgame

The old audit equated the number of raids with daily rows. Native daytime incursions can also occur when attraction reaches 10,000, so this can reject valid survival evidence. The updated audit requires one distinct night incursion for every completed combat night, while separately counting additional daytime incursions. Duplicate night raids, duplicate retained IDs, out-of-range days, missing night coverage and mismatched native spawn counters are rejected. Night destruction reference curves exclude daytime raids; all raids still participate in actual consumed-hit accounting.

For a peaceful completed horizon beyond day100, the audit requires a native compressed snapshot with postgame=true/result=null, matching day/night/time/ledger and no active raid. The preserved day100 row must record victory, subsequent rows have no terminal result, and the complete event counters must show exactly one CampaignWon and one PostgameStarted with no GameOver. No observed raid may occur after day100. The normal ledger, physical delivery, source, transport and strike checks continue to apply. This branch covers successful postgame horizons; a defeat during postgame still requires separate phase-specific investigation if observed.

Nine parser tests pass, including a clearly synthetic 180-day fixture and rejection of false postgame, missing victory, duplicate transitions, defeat counters, unfinished time, active raid and an illegal postgame daytime raid. These fixtures are parser checks, **not native 100/180 campaign acceptance**. The unchanged v107/v108/v109 real seven-night archives and v110 archive pass the expanded auditor, with fresh separate regression outputs retained.

No live simulation or observer was edited. The priority v111 hundred-night campaign remains responsible for providing actual long-horizon evidence. A legitimate victory still requires its exact hundredth-dawn snapshot and completed last native raid; an estimated or synthetic horizon does not qualify.
