# Rejected wider-residency search experiment

The read-only retained-snapshot probe used the original complete night-13 wave and unchanged native selection on copied states. Padding each active bound by 0, 24, 48 and 96 metres produced no accepted entry in any case. Measured single CPU selection times were 3116.75, 10085.18, 76666.69 and 365522.01 milliseconds respectively. These are isolated Node measurements, not browser GPU/frame benchmarks or repeated statistical estimates.

Merely expanding the region is rejected: it fails to solve the entry and drastically increases procedural/search work. No expansion setting has been applied to production. The JSON retains original snapshot SHA, source hashes, exact bounds, pending composition, timings and null results. The process completed normally; the observation delay did not trigger a duplicate probe, synthetic spawn or economic defeat.

The separate projected-seed candidate instead reuses an already examined exterior position and requires a positive native full-radius detour. Its native replay and regression evidence are recorded separately. Neither experiment approves the full 100-night economic model.
