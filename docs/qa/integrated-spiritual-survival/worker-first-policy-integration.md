# Explicit worker-first campaign candidate

The new `--perimeter-qa worker-first-v4` option uses worker-service v3 and incremental crop certification, checking the necessary worker precondition before the expensive animal certificate. Defaults and the earlier `legacy` and `incremental-v3` labels retain their behavior. It changes QA proof ordering, not game prices, damage, navigation or economic transactions.

Fourteen focused tests pass: CLI contracts, cooperative stopping/error preservation, actual paid native Canyon completion under all three modes, worker rejection, successful complete physical certification and open animal perimeter rejection.

Worker failures remain transient: `native-worker-centre-service-unproven` cannot enter the static failed-planning cache. A proposal failing both animal and worker access can now expose the worker failure first and thus be retried rather than memoized as a static failure. This deliberately preserves safety when workers move; it can increase retries in such cases. No failed worker proof approves a perimeter.

The full-search experiment starts a **fresh policy** on a copied terminal v113 snapshot. It does not restore the historical completed/planned contour, so its results must not be described as a replay of the original last decision. Both modes use the same copied snapshot, policy options and protected cash, and allow only actual native commands on that copy. Original campaign artifacts remain untouched.

Worker-first completes its fresh search in 9,915 ms, with 21 attempts, no native commands or payments and byte-identical simulation state. It finds no certified bounded contour. This is a complete QA search measurement, not a GPU/gameplay benchmark or campaign survival result. Remaining routing/search cost is significant; the isolated 99.63% reduction for one rejected rectangular proposal cannot be generalized to the complete search or campaign.

The earlier mode completes the same fresh-policy experiment in 247,900 ms. Both produce 21 attempts, no commands/payments, unchanged state and the final reason `no-bounded-legal-contour`. The single sequential full-search comparison reduces measured time by approximately 96%; it is not an AB/BA repeated estimate. Individual failure diagnostics can differ by proof precedence. The raw reports retain all failures and source hashes.

The 100-night campaign remains unvalidated. Do not promote balance or interpret stopped v113 as economic defeat. A long retry needs a satisfactory complete-policy throughput gate, not merely passing a small fixture.
