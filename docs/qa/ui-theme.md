# Shared styles for production menus and controls

`public/ui-theme.css` is loaded by the game, original menu and original new-game selector. Their generators include the same stylesheet so regenerating those pages does not lose the theme. The packaged stylesheet links remain relative under the itch.io subdirectory build.

Shared tokens cover Banga control text, Ga Maamli dialog titles, paper/forest/gold colors, border radii, primary/secondary actions, keyboard focus, disabled states and reduced-motion behavior. Primary text buttons use the recruitment panel's original green palette. Recruitment confirmation, selector confirmation and ordinary text actions have a 44 px minimum height; illustrated HUD controls retain their native dimensions and backgrounds. Existing menu transitions, HUD frames and portraits remain in place.

Active press movement applies only to ordinary text buttons. A blanket transform was rejected during testing because projected menu hotspots already depend on their own transforms: moving them during pointer-down could prevent click activation. The final menu opens Options by mouse as well as keyboard.

Rendered checks cover the original menu's Options section and the original selector, plus the actual production recruitment markup and frame drawing through `tests/browser/ui-theme.html`. At 390×844, selector and recruitment have no horizontal overflow, all four portraits load, and recruitment confirmation measures 44 px with Banga text. Screenshots: [selector](ui-theme/selector-mobile.png), [recruitment portrait](ui-theme/hiring-mobile.png), [recruitment landscape](ui-theme/hiring-landscape.png), [menu options](ui-theme/menu-options.png).

The recruitment fixture renders production markup, CSS and art without a simulated world or saving a user slot. It verifies styling and asset loading, not hiring gameplay.

The additional complete-game walkthrough uses `tests/browser/mobile-first-day.html`, with an isolated IndexedDB namespace and in-memory settings so real player saves are not changed. It builds the first centre, plants millet, pays for an older worker and resumes that saved game through the original Continue screen. Loading covers the world before the HUD becomes visible. At 390×844, pause actions use the original recruitment green gradient and measure 44.8 px high; construction's close target measures 44×44 px. Construction, cultivation and magic replace the preceding panel. Crop prices remain ascending. Settings return to pause. At 844×390, construction fits within the viewport without horizontal overflow. These are browser viewport checks, not physical-phone performance measurements.

Screenshots from the complete game: [construction portrait](ui-theme-panels/build-mobile.png), [construction landscape](ui-theme-panels/build-landscape.png), [cultivation](ui-theme-panels/crops-mobile.png), [magic](ui-theme-panels/magic-mobile.png), [pause](ui-theme-panels/pause-mobile.png), [settings](ui-theme-panels/settings-mobile.png). Theme URLs carry a version query to refresh the earlier cached stylesheet. Contextual building/wall panels, remaining English views and physical-phone interaction still require visual review.

A subsequent actual-game walkthrough reopens midday recruitment from the centre; all four portraits load ([midday hiring](ui-theme-panels/hiring-midday.png)). It draws six bramble pieces through the normal pointer stroke, paying 60 coins, resumes that saved world and selects a wall ([wall actions](ui-theme-panels/wall-context.png)). Generic text actions now default to the shared `primary` class, including repair, removal and village confirmation; explicit ghost/secondary actions retain their existing roles. The wall removal button uses the same green gradient and measures 64 px high with wrapped text. During an active raid it remains disabled under the existing gameplay rule.

Switching the fixture's language through real settings verifies [English settings](ui-theme-panels/settings-english-mobile.png), [English pause](ui-theme-panels/pause-english-mobile.png), [English crop choices](ui-theme-panels/crops-english-mobile.png) and [English powers](ui-theme-panels/magic-english-mobile.png) at 390×844. In portrait, the illustrated panel covers the side buttons; close the current panel before selecting another action. No global runtime errors were recorded. The production build and web package check also pass after the generic-action change. Village confirmation, result screens, a damaged-building repair and physical-phone interaction remain outside this visual walkthrough.
