# Sabana: cuatro especies, doce recorridos

Fuente `aef4b25`, rendering `a0fb5ce`, base main `ebce9b1`. Semilla 712, Mapungubwe, calidad media, transición 120–160 m y bruma 30–300 m. Cada especie utiliza el mismo ID en aproximación diurna (25–180 m), órbita nocturna y barrido lateral diurno.

Los doce recorridos completaron con estado idéntico, errores/WebGL 0 y descensos visibles, desconocidos y del árbol objetivo 0. Se conservan los 1.918 descensos globales, clasificados por bounds individuales fuera del frustum; el informe completo contiene identidad, packing y firmas de recursos.

Este resultado acredita continuidad de esas rutas, **no aceptación artística ni ganancia de rendimiento**. Las capturas conservan tramado lejano y una franja plana del horizonte. La salida diagnóstica visible creció durante la secuencia; no se usa su ritmo como FPS. Hubo suite CPU completa y campañas de fondo. El estimado RGBA+mips de cuatro pares de atlas es 42,67 MiB y el backdrop 5,33 MiB; los contadores renderer no son RAM del driver.

La integración permanece experimental y OFF en gameplay normal. Faltan otras especies/biomas, calidades, inclinaciones y el coste actualizado.
