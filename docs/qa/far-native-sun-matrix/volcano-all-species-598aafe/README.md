# Volcanes: cuatro especies, doce rutas

Fuente `598aafe`, runtime equivalente a `5afd8e2`. Semilla 712, Mapungubwe, calidad media, transición 120–160 m y bruma 30–300 m.

Las doce rutas completan con estado idéntico, errores/WebGL 0 y descensos visibles/desconocidos/del objetivo 0. Se conservan los 1.673 descensos globales fuera del frustum individual en el informe completo, sin ocultar cambios de recursos ni packing. Cada especie recorre aproximación diurna, órbita nocturna y desplazamiento lateral diurno.

`night.png` captura la segunda especie durante noche completa (`night=1`). La banda uniforme del suelo y el tramado lejano siguen pendientes de aceptación visual. **No ganancia FPS ni aceptación artística**: visor instrumentado y campañas CPU de fondo. Estimados RGBA+mips del bioma activo: 42,67 MiB atlas y 5,33 MiB backdrop; no equivalen a memoria del driver. OFF en gameplay normal.
