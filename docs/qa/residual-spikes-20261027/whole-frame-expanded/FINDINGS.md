# Whole-frame diagnostic: regional completion remains a tail candidate

Two original-runtime diagnostic traversals completed without page/console errors. Both preserve active simulation and the same forty-second Manglares excursion. This is attribution, not performance acceptance; second run enables CPU sampling and all available loading spans.

First run (whole-frame-attribution): synchronous main callback P95 17.405ms, World.render16.610ms, mandatory work outside renderer P95 .855/max2.095ms. Scheduler synchronous prefix max23.345ms. Browser Long Animation Frame observer reports123 slow frames, including one far-scene-loader Worker.onmessage script of42.120ms. This excludes interpreting all presentation delay as main-thread CPU.

Expanded run: main synchronous P95 20.480ms; non-render mandatory P95 .990/max2.510ms. Scheduler synchronous prefix max30.480ms. Two slow frames contain Worker.onmessage attribution (max58.670ms). Source inspection shows that callback settles a promise after removing listeners and terminating the worker; continuations then filter/map trees, create a prototype, attach ground and prepare GPU resources. Browser attribution alone does not isolate deserialization, termination, or promise continuations. Transferable buffers already exist; do not assume a missing transfer list.

Important instrumentation limitations: endFrame is async, so the wrapper measures only its synchronous prefix. Async continuation CPU is outside mainSyncMs. Some far-region witnesses are captured as null when layers are first constructed, before this late-installed probe. Expanded spans therefore include initial-far-region-fallback (5698.975ms awaited latency, NOT CPU time), but do not resolve the regional create/attach phases. No dropped span rows. CPU profile descendant samples are statistical, include warmup, and cannot independently assign the observed58ms interval. worker-descendants.json is exploratory full-profile evidence, not exact-time attribution.

Next action: install targeted receiver/termination and create/attach witnesses before regional layer construction, preserve their scope, and correlate those spans with browser slow frames. Also attribute individual scheduler units responsible for23–30ms prefixes. Do not preemptively split a specific operation or blame the driver without that evidence. The unchanged production renderer remains active; no optimization has been adopted from these runs.

Reproduction: run-whole-frame-attribution.mjs or run-whole-frame-expanded.mjs, summarize-whole-frame-attribution.mjs with the corresponding output directory, and summarize-whole-frame-spans.mjs for expanded data. Raw reports/profiles are stored as gzip; restore original names before replaying summaries. Provenance records runtime/harness hashes and environment. Long Animation Frame data measures browser-reported slow frames, never pure GPU execution.
