# QA shared approach certificate, OFF

This candidate changes only a QA service proof, with explicit `sharedCertificate: true` required by callers. All existing perimeter-policy callers retain the default OFF. Gameplay, prices, clock, magic, animal targets, geometry and crop/worker state are unchanged. Parent evidence is the no-walls short control `b8713a12`; integrated mechanics remain `ae846841`.

The helper reproduces the complete-closed-region early null return of native reversed animal approach searches. It retains failed-path priority, declines shortcuts when prepared/query-scoped results exist, validates the exterior endpoint and direct segment, enumerates every actual 3x3 origin connector and requires complete cached regions for all of them. Any region with an actual connector to the destination forces ordinary navigation. Empty/unknown regions also fall back. Certified failure writes the same failed-path key with the native FIFO capacity rule. Modified navigation search implementations do not use this shortcut.

The service proof preserves target/32-angle order, body/contact checks, direct-route check, enclosure membership, empty-frontier physical connector fallback, reason and counters. Only the repeated `approachPath` call can be skipped. Native navigation already exploits these same certificates internally: this is not evidence that thousands of A* traversals were removed, nor a replacement for a cold component search.

`node --test tests/native-service-shared-certificate.test.js tests/native-service-component-proof.test.js` passes 10/10, latest 979.623 ms. Logs from both directed runs are compressed byte-exact. Tests cover complete closed native components, open geometry, exact complete reports/state, prepared and query cache priority, incomplete/empty connector cases, epoch clearing, and a bounded two-crop query from the retained real paid-farm snapshot. The controlled closed-component unit uses explicit flat terrain/no props and four native solid obstacles: it is a navigation unit, not a legally paid perimeter or farm-defense acceptance. The real snapshot test changes no state or terrain, but its bounded report may terminate on an open route and does not cover the original expensive 19-candidate workload.

The warm unit AB/BA descriptive sample is A1 11.6132, B1 7.0067, B2 8.3941, A2 7.7974 ms. This small sample is not a significant or campaign-scale performance acceptance. It includes warm geometry, JIT/order effects and shared valid native caches. No renderer/GPU test, campaign or default activation follows it. The preceding full terrain-query memoization regression (+47.94%) stays preserved on its separate branch and is not reinterpreted.

The receipt records all 443 native/QA source hashes, both original logs and the original real snapshot hash. Inactivity is no longer measured as an objective or acceptance gate by explicit user decision; historical pilot output is not rewritten. Further work needs exact full perimeter-decision parity and meaningful reduction on a bounded representative expensive fixture before any protected campaign is justified.
