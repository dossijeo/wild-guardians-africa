# Private QA lattice memo and concrete terrain/collision diagnostic

The retained protected CPU profile attributes exclusive sampled time to lattice 166.14 s, coarseSegmentClear 69.85 s, fluidInside 47.34 s, slope 44.77 s and surface 36.11 s. A* is 17.56 s. The earlier exact high-level terrain-query cache worsened cost 47.94%; a closed-component shortcut saved only 4.49%. This new hypothesis targets lower-level repeated pure integer lattice heights, not terrain/body legality or any geometry restriction.

`withNativeProofLatticeCache` creates a temporary private navigation/field wrapper for one synchronous read-only QA proof. Original navigator, field methods, geometry and state are not patched. All height misses use the native lattice function and arithmetic, including its existing 12,000-entry FIFO height cache. Exact numeric x/z keys use nested Maps; no coordinate rounding, quantization, interpolation change or new RNG occurs. Capacity is 65,536 entries per lease, then misses remain native without eviction. Nonfinite coordinates and negative zero bypass. Memory is released on completion/error; escaped views return to the original field.

Mode `off` is the default and leaves the original view unchanged. `diagnose` counts surface/lattice/coarse collision calls with the same wrapper but executes every native lattice call. `cache` additionally counts actual lattice hits/misses/capacity bypasses. The expensive A/B fixture uses diagnose for A and cache for B, so both have the same counter/wrapper instrumentation. This measures cache efficacy in an instrumented fixture, not uninstrumented production performance. The earlier closed-approach certificate remains OFF in both arms. No collision result is memoized or assumed clear.

Ownership is a synchronous pure lease, not a persistent world cache. Navigation epoch changes clear the numeric cache. Full deep terrain input/config identity and immutable native-method references are checked before returning a proof: unexpected field/config/prototype/coarse-method changes reject the entire result with an actionable error, rather than returning a stale certificate. Tests deliberately mutate relief/prototypes and confirm rejection. Native cache warmth is not byte-identical: extra heights can be served without touching native FIFO/pond-neighborhood caches. Deterministic outputs, complete decisions and serialized physical/economic state must still be exact. This wrapper is not intended for callbacks that execute gameplay commands or mutate physical inputs.
