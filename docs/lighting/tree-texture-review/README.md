Verified all four POSITION, TEXCOORD_0 and index arrays equal the current runtime-export models, comparing decoded values rather than assuming identity. The viewer goes further: it clones the original tree, sharing its original geometry (including normals), clones its material and replaces only color, normal, roughness and metalness maps from the corresponding HD asset. No UV transfer or rebake is necessary for this archive.

Actual browser inspection: all four day side-by-sides, tree 4 close detail and tree 4 illustrative night. Captures use the same renderer/light/camera setup as the model comparison. Silhouettes and triangle counts are unchanged. Foliage and bark align in the inspected views; this is not an exhaustive every-texel/seam audit. Tree 2 retains the original isolated foliage piece in both versions, confirming it is not caused by the texture swap.

Visual assessment: visibly cleaner bark grain, more distinct foliage texture and less muddy rocks/base. It is also a repaint: greener leaves, warmer/orange trunks, much lighter dry wood. Some of the perceived improvement is palette/contrast, not resolution alone. A distance-triggered switch would change color even with identical geometry. Match palettes or use downsampled versions of the same new maps at all distances before judging transitions.

Raw source textures are 8192-square color + two 4096-square maps per tree. Estimated RGBA8 with mip chains: 512 MiB per tree, 2 GiB for all four; analytical estimate, not measured GPU allocation. Viewer releases previous pair resources between trees. File compression does not provide GPU texture compression. Do not ship these raw maps for an integrated-GPU target. Evaluate 2048 color/1024 normal-PBR candidates, then GPU compression and bounded residency. No claim that lower resolutions retain all this quality without a further comparison.

Recommendation: texture upgrade is the better fit for retaining existing trees and is worth pursuing in optimized form. Raw 8K/4K delivery is not justified for these screen sizes. No production integration, full Wild Engine shader/AO review, GPU timing or FPS acceptance was performed; these are isolated WebGL comparison renders. The geometry replacement experiment remains rejected per user direction.
