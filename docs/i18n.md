# English and Spanish runtime

The game supports `en` and `es`. A saved explicit choice wins over the browser's ordered `navigator.languages` and then `navigator.language`. Regional variants such as `es-MX`, `es-ES` and `en-GB` resolve to their supported language. Unsupported or unavailable preferences fall back to English. Storage failures do not prevent the game from starting.

The Language selector is available in the native menu's Options and the game's Settings. A change updates presentation in place. The save, simulation clock, money, hiring draft, input values, entity IDs and native navigation animations are preserved. Same-origin parent/child frames exchange validated language messages; storage events synchronize other tabs. A nested selector frame inherits the parent's choice, including when storage is unavailable.

## Catalog and coverage inventory

`public/i18n/translations.tsv` is the reviewed Spanish-source/English catalog (1,519 entries). Regenerate `messages.js` with `python tools/build_i18n_catalog.py`. Duplicate and empty entries fail generation. Named interpolation and plural rules cover notices and quantitative labels. Matching uses Unicode word boundaries, ignores logical identifiers and file paths, and never feeds translated output back into its source pass.

The DOM adapter keeps each node's original source in a WeakMap. New nodes and changed text/ARIA/title/alt/placeholder attributes are localized through a MutationObserver. Repeated changes restore the latest source text in both directions without replacing controls. Scripts, styles, code, preformatted technical data, editable text areas and `data-no-i18n` are excluded.

`docs/i18n-inventory.json` maps 2,996 presentation candidates to source locations. It also contains technical identifiers and renderer metadata: its count is **not a translation coverage percentage**. Regenerate it with:

```sh
node tools/extract_i18n_literals.mjs
python tools/inventory_i18n.py
```

The intermediate raw AST list stays in `.cache`. The inventory includes text split by inline markup, punctuation-leading fragments and semicolons; these previously hid several long library explanations. `docs/i18n-sfx-labels.json` records the 16 categories and 126 sound entries reviewed without copying audio payloads.

The renderer's internal VFX/surface/terrain descriptions and source-only QA fixture labels are outside player-facing runtime UI. They are inventoried as source material; this change does not assert they are translated. Native animation clip identifiers, asset filenames, proper names, SHA hashes and schema fields remain original. Archived labs, plan documentation, exported reference JSON/CSV and the SFX ZIP's original technical readme remain authored reference material. Existing music, effects and character vocalizations are preserved; this change does not provide translated voice recordings. The title/logo and named music track remain original branded graphics/text. No translated text has been baked into model textures.
